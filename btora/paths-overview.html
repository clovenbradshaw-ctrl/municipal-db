How bookings get in: vendor delivery × system folds

The vendor can deliver STR data three ways — live stream, file export, or static API (columns). Each delivery lands in three places — Swarm, Slate, and Building Blocks (rows). Every arrow is a genuine EO transformation: steps that can't name inputs + rule refuse instead of guessing.
